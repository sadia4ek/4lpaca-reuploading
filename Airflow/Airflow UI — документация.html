Обзор

Airflow — библиотека интерфейса для Roblox-экзекьюторов (автор 4lpaca, MIT). Позволяет создавать окно с вкладками, элементами управления, всплывающими уведомлениями, сохранением конфигов и отдельным «загрузчиком» (лоадером) для нескольких игр/версий.

Все примеры — реальный Luau-код на основе исходника библиотеки. Названия переменных внутри GUI генерируются случайно (Airflow:RandomString()), поэтому в примерах используется только публичный API.

Быстрый старт

local Airflow = loadstring(game:HttpGet("URL_ДО_AIRFLOW"))()

local Window = Airflow:Init({
    Name = "My Script",
    Logo = "http://www.roblox.com/asset/?id=118752982916680",
    Keybind = "Delete",      -- клавиша показать/скрыть
    Hightlight = Color3.fromRGB(163, 128, 216),
    Resizable = false,
    UnlockMouse = false,
    IconSize = 20,
    Version = "1.0",         -- для проверки конфигов
})

local Tab = Window:DrawTab({ Name = "Main", Icon = "home" })

Tab.Left:AddToggle({
    Name = "God Mode",
    Default = false,
    Callback = function(value)
        print("God mode:", value)
    end,
})

Вкладки — Window:DrawTab(config)

ПолеОписание

Возвращаемый Tab содержит две колонки — Tab.Left и Tab.Right, каждая из которых сама является объектом элементов (см. раздел «Элементы»).

Поле / методОписание
Tab.Left / Tab.RightЛевая/правая колонки — добавляйте элементы напрямую: Tab.Left:AddToggle(...)
Tab:AddSection(config)Создаёт группу элементов с подписью внутри колонки (см. ниже)
Tab:Disable(value, reason)Блокирует вкладку и показывает текст причины
Tab.Disabledboolean — текущее состояние блокировки

Секции — Tab:AddSection(config)

ПолеОписание
NameЗаголовок секции, по умолчанию "Section"
Position"left" или "right" — в какой колонке разместить
local Section = Tab:AddSection({ Name = "Combat", Position = "left" })
Section:AddToggle({ Name = "Aimbot", Callback = function(v) end })

Возвращает объект элементов — тот же интерфейс, что и Tab.Left/Tab.Right.

Элементы

Добавляются через Tab.Left, Tab.Right или объект секции. У каждого метода одинаковая сигнатура :AddX(config).

:AddLabel(name)

Простая текстовая строка. Принимает строку напрямую, а не таблицу конфига.

local lbl = Tab.Left:AddLabel("Версия скрипта: 1.2")
lbl:Edit("Новый текст")

ПолеТипПо умолчанию
Namestring"ColorPicker"
DefaultColor3Color3.fromRGB(255,255,255)

Открывает общий на всё окно попап-пикер (HSV-колесо + полоса). В попапе есть кнопки Copy / Paste для переноса цвета между разными color-picker'ами.

Попап цветового пикера один на всё окно (Airflow.Features) — при открытии одного пикера предыдущий закрывается автоматически.

Общий API каждого элемента

Кроме отдельных случаев (Label, Paragraph), каждый элемент возвращает объект со следующими методами:

МетодОписание
:Edit(text)Изменить подпись элемента
:SetValue(value)Программно задать значение (кроме Label/Button/Paragraph)
:Visible(bool)Показать/скрыть элемент
:Destroy()Удалить элемент

FileManager — сохранение и загрузка конфигов

МетодОписание
Airflow.FileManager:WriteConfig(Window, path)Сохраняет текущие значения всех элементов в файл (writefile), возвращает JSON-строку
Airflow.FileManager:GetConfig(Window)Возвращает JSON-строку без записи на диск
Airflow.FileManager:LoadConfig(Window, path, VERSION)Читает файл и применяет значения к окну
Airflow.FileManager:LoadConfigFromString(Window, str, VERSION)То же, но из готовой JSON-строки
Airflow.FileManager:GetVersion(path)Считывает поле VERSION из файла конфига
VERSION, переданный в LoadConfig, должен совпадать с версией, указанной при Init — иначе загрузка отклоняется с предупреждением в консоль.
Airflow.FileManager:WriteConfig(Window, "myconfig.json")
-- ...
Airflow.FileManager:LoadConfig(Window, "myconfig.json", "1.0")

Уведомления — Airflow:Notify(config)

ПолеТипПо умолчанию
Titlestring"Notification"
Contentstring""
Durationnumber | boolean5

Если Duration — boolean, уведомление не скрывается автоматически и возвращает объект управления:

local n = Airflow:Notify({ Title = "Загрузка", Content = "0%", Duration = true })
n:SetContent("50%")
-- позже:
n:Close()

Airflow:DrawList(config) отдельное окно ключ-значение

Компактное перетаскиваемое окошко (например, для watermark/статистики), не связанное с основным окном.

ПолеПо умолчанию
Name"keybinds"
Icon"keyboard"
МетодОписание
List:AddFrame({ Key, Value })Добавляет строку «ключ — значение», возвращает объект с :SetKey(), :SetValue(), :Visible()
List:Visible(bool)Показать/скрыть всё окно
local Watermark = Airflow:DrawList({ Name = "Info", Icon = "activity" })
local fps = Watermark:AddFrame({ Key = "FPS", Value = "60" })
fps:SetValue("144")

Airflow:DrawLoader(loader_config) мульти-игровой лоадер

Экран выбора игры и версии загрузки — типичный паттерн «loader hub» для чит-скриптов.

ПолеПо умолчанию
Name"airflow"
Iconстандартный логотип
Highlightакцентный цвет
local Loader = Airflow:DrawLoader({ Name = "My Hub" })

local CS = Loader:DrawGame({
    Name = "Counter Blox",
    Logo = "rbxassetid://0",
    Description = "Welcome!",
})

CS:SetStatus(CS.Enum.StatusTypes.Online)

CS:DrawVersion({
    Name = "Live",
    Status = CS.Enum.StatusTypes.Online,
    LastUpdate = os.time(),
    LoadScript = 'loadstring(game:HttpGet("URL"))()',
})
Статус (Enum.StatusTypes)Цвет
Onlineзелёный
Updatingжёлтый
NotUpdateкрасный
Outdateкрасновато-розовый
Unknowкрасный, текст «???»

LoadScript может быть строкой Lua-кода (выполняется через loadstring) либо напрямую функцией. При успешной загрузке лоадер закрывается и уничтожается.

Иконки (Lucide)

Библиотека включает ~700 иконок из набора Lucide, загруженных как rbxassetid.

МетодОписание
Airflow:GetIcon(name)Вернуть asset id по имени (с префиксом lucide- или без)
Airflow:SetIcon(name, assetId)Добавить/переопределить свою иконку
Airflow:LoadAssets()Предзагрузить все иконки через ContentProvider:Preload
Icon.Image = Airflow:GetIcon("home")       -- lucide-home
Icon.Image = Airflow:GetIcon("lucide-trophy")
